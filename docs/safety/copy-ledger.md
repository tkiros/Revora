# Revora Copy Ledger

## Purpose

This ledger tracks every active or planned product, prompt, result, and launch
string against the approved claims boundary. The validator only scans rows that
are both approved and active so policy documents can still record banned
language safely.

## Approval Rules

- `Status` shows whether the row is still draft, approved, or retired.
- `Active` shows whether the row is part of the current MVP surface.
- `Allowed Claim Class` must match a class in `claims-boundary.md`.
- `Evidence Rows` points to the evidence pack rows that justify the narrow
  allowed-use statement behind that string.

## Keep-Most Phrasebank Selection (Task 7.1)

The "Enjoy it anyway" keep-most phrase is a single deterministic constant shown on
every Be-careful (MODERATE) and Hold-off (HIGH) result, alongside `SEQUENCING_TIP`.
Because the derivation is component-blind, the phrase must be safe and TRUE for any
flagged meal — including sugary drinks, which the model can flag `high_risk`
(floored to HIGH by the only deterministic floor, `lib/revora/postprocess.ts:154-161`)
or `carbs_only` (floored to MODERATE), and which have no starchy, sweet-vs-savory,
plate, or fat "part".

- Selected `KEEP_MOST` constant: `keep-most-02` — "Enjoy a smaller portion now and
  set the rest aside for later — same food, gentler pace." It is the strongest
  survivor because it names no meal component, so whole-portion moderation stays
  true regardless of the culprit (refined carbs, sugar, portion size, or fried food).
- Approved phrasebank alternates: `keep-most-09`, `keep-most-10` (also
  component-agnostic).
- Held as Draft fallbacks (audit-clean but assume a separable carb-heavy part;
  defensible under the carb/glucose framing of MODERATE/HIGH but less universal):
  `keep-most-01`, `keep-most-06`.
- Rejected on truth grounds (a component assumption that can be false for some
  flagged meals): `keep-most-03`, `keep-most-04`, `keep-most-05`, `keep-most-07`,
  `keep-most-08`.

All ten survived the mechanical regex families (BANNED, coach-tone, and the ledger
validator's fixture patterns); the eliminations above are judgment calls on
whether the phrase stays true for every MODERATE/HIGH meal. Approved keep-most rows
carry `Active: No` until the constant is wired into product code in Phase 7.
